## 🌟 Overview

**Samuel Collridge Naik Portfolio V2** is a futuristic, highly responsive, and interactive digital universe showcasing production software engineering, applied machine learning pipelines, and spatial computer vision prototypes.

Designed with an aesthetic of **Futuristic × Experimental × Luxury Tech**, it combines:
- Custom 3D WebGL computational object and particle swarm
- An interactive 2D gravitational **Technology Constellation** linking skills directly to production projects
- **The Lab**: 4 live interactive micro-experiments (Neural Latent Space Manifold Probe, Edge & Spatial Convolution Kernel Inspector, Web Audio Parametric Synthesizer, and A* Heuristic Grid Router)
- Deep, honest **Case Studies** for each major system (Toxic Comment Detection, Geo-Spatial Infrastructure Monitoring, SDA Inter College Bahraich Website, and more)
- Verified credential and certificate inspector
- Print-ready and downloadable verified resume (.md export and clean print view)
- Custom adaptive cursor with magnetic pull and velocity tracking (coarse/touch disabled)

## 🚀 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/samuelcollridgenaik-alt/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the application.

4. **Run Typecheck & Lint**:
   ```bash
   npm run lint
   ```

5. **Build for Production**:
   ```bash
   npm run build
   ```
